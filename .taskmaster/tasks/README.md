## 작업 진행 방법

1. **순서대로 진행**: dependencies를 고려하여 순차적으로 진행
2. **체크리스트 활용**: 각 작업의 Acceptance Criteria를 모두 완료
3. **문서화**: 구현 완료 시 코드 주석 및 README 업데이트
4. **테스트**: 각 기능 구현 후 반드시 테스트 진행
