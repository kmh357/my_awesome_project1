## 시작하기

### 찍찍이란?

찍찍이는 초등학생 여러분이 오늘 해야 할 일을 잊지 않고, 재미있게 관리할 수 있도록 도와주는 앱이에요!
할 일을 완료할 때마다 귀여운 스티커를 받을 수 있어서 숙제도 더 재미있게 할 수 있어요. 🎉

### 첫 화면 알아보기

찍찍이를 열면 다음과 같은 화면이 나와요:

```
┌─────────────────────────────────────────┐
│     찍찍이 (Tick-Tick-E)                │
│     오늘도 화이팅! 💪                    │
├─────────────────────────────────────────┤
│  [어제] [오늘] [내일]  [날짜 선택]      │
├─────────────────────────────────────────┤
│  할 일 입력창                  [추가]   │
├─────────────────────────────────────────┤
│  오늘의 할 일        0/0               │
│  ▱▱▱▱▱▱▱▱▱▱ 0%                       │
├─────────────────────────────────────────┤
│  [할 일 목록이 여기에 나타나요]         │
└─────────────────────────────────────────┘
│  [📝 할 일]  [🎨 스티커]              │
└─────────────────────────────────────────┘
```

## 할 일 관리하기

### 1. 할 일 추가하기 ✏️

**단계별 안내**:

1. **입력창 찾기**
   - 화면 위쪽에 있는 큰 입력창을 찾아요
   - "예: 수학 숙제하기, 강아지 밥 주기" 라고 적혀 있어요

2. **할 일 적기**
   - 오늘 해야 할 일을 입력창에 적어요
   - 최대 50글자까지 쓸 수 있어요
   - 예시: "수학 숙제 10페이지", "영어 단어 외우기"

3. **추가 버튼 누르기**
   - 오른쪽의 파란색 "추가" 버튼을 눌러요
   - 또는 키보드의 Enter 키를 눌러도 돼요

4. **완료!**
   - 할 일이 아래 목록에 나타나요
   - 글자 수가 "1/0" → "1/1"로 바뀌어요

**💡 꿀팁**:
- 구체적으로 적으면 나중에 확인하기 쉬워요
  - ❌ "공부하기"
  - ✅ "수학 문제집 15페이지부터 20페이지까지"
- 너무 긴 할 일은 나눠서 적어보세요
  - ❌ "수학 숙제하고 영어 단어 외우고 일기 쓰기"
  - ✅ "수학 숙제", "영어 단어 외우기", "일기 쓰기" (3개로 나누기)

### 2. 할 일 완료하기 ✅

**단계별 안내**:

1. **동그라미 찾기**
   - 각 할 일 왼쪽에 있는 빈 동그라미를 찾아요

2. **동그라미 누르기**
   - 동그라미를 누르면 파란색으로 바뀌고 ✓ 표시가 나타나요
   - 할 일에 줄이 그어지고 회색으로 바뀌어요
   - 반짝이는 별 ✨이 나타나요!

3. **스티커 받기 🎁**
   - 화면 중앙에 큰 팝업이 나타나요
   - "정말 잘했어요!" 같은 칭찬 메시지가 보여요
   - 귀여운 스티커를 받아요! (토끼, 고양이, 별 등)
   - 스티커의 등급도 확인할 수 있어요:
     - ✨ 일반 (자주 나와요)
     - 💎 레어 (가끔 나와요)
     - 🌟 에픽 (드물어요)
     - 👑 전설 (아주 드물어요!)

4. **확인 버튼**
   - "확인" 버튼을 눌러요
   - 스티커가 자동으로 모음판에 저장돼요

**💡 꿀팁**:
- 할 일을 다 끝낸 후에 체크하세요
- 실수로 체크했다면? 다시 동그라미를 누르면 체크가 풀려요
- 모든 할 일을 완료하면 "모두 완료했어요! 최고예요!" 메시지가 나와요

### 3. 할 일 수정하기 ✏️

**단계별 안내**:

1. **할 일 텍스트 클릭**
   - 수정하고 싶은 할 일의 글자 부분을 클릭해요
   - (⚠️ 주의: 완료된 할 일은 수정할 수 없어요)

2. **텍스트 수정**
   - 입력창으로 바뀌어요
   - 글자가 자동으로 선택되어 있어요
   - 수정하고 싶은 내용을 입력해요

3. **저장하기**
   - **방법 1**: Enter 키를 눌러요
   - **방법 2**: 다른 곳을 클릭해요 (자동 저장)
   - **방법 3**: Esc 키를 누르면 수정이 취소돼요

**예시**:
```
수정 전: "수학 숙제하기"
       ↓ (클릭)
입력창: "수학 숙제하기" (선택된 상태)
       ↓ (수정)
입력창: "수학 문제집 10페이지 풀기"
       ↓ (Enter 또는 외부 클릭)
수정 후: "수학 문제집 10페이지 풀기"
```

**💡 꿀팁**:
- 빈 칸으로 저장하려고 하면 저장이 안 돼요
- 수정하다가 마음이 바뀌면 Esc 키를 눌러서 취소할 수 있어요

### 4. 할 일 삭제하기 🗑️

**단계별 안내**:

1. **X 버튼 찾기**
   - 각 할 일 오른쪽에 있는 작은 X 버튼을 찾아요

2. **X 버튼 누르기**
   - X 버튼을 누르면 확인 메시지가 나타나요
   - "이 할 일을 삭제할까요?"

3. **확인 또는 취소**
   - **확인**: 할 일이 목록에서 사라져요
   - **취소**: 아무 일도 일어나지 않아요

**⚠️ 주의**:
- 삭제한 할 일은 다시 되돌릴 수 없어요
- 잘 생각하고 삭제 버튼을 누르세요

## 날짜별로 보기

### 날짜 선택하기 📅

찍찍이는 여러 날짜의 할 일을 관리할 수 있어요!

**방법 1: 빠른 버튼 사용**

1. **어제 버튼**
   - 어제의 할 일을 봐요
   - 어제 뭘 했는지 확인할 수 있어요

2. **오늘 버튼** (기본)
   - 오늘의 할 일을 봐요
   - 앱을 열면 자동으로 오늘이 선택되어 있어요

3. **내일 버튼**
   - 내일의 할 일을 미리 적을 수 있어요
   - 내일 할 일을 준비해보세요

**방법 2: 날짜 직접 선택**

1. **날짜 입력창 클릭**
   - "다른 날짜:" 옆의 날짜 입력창을 클릭해요

2. **달력에서 선택**
   - 달력이 나타나요
   - 원하는 날짜를 클릭해요
   - 과거 날짜, 미래 날짜 모두 선택 가능해요

3. **할 일 확인**
   - 선택한 날짜의 할 일이 나타나요
   - 날짜를 바꿔도 할 일은 사라지지 않고 저장되어 있어요

**사용 예시**:

```
월요일: "수학 숙제하기", "영어 단어 외우기"
화요일: "과학 실험 준비", "도서관 책 반납"
수요일: "미술 준비물 챙기기"
```

**💡 꿀팁**:
- 주말에 다음 주 할 일을 미리 적어두면 좋아요
- 방학 때는 매일매일 계획을 세워보세요
- 특별한 날 (생일, 소풍 등)의 준비물을 미리 적어두세요

## 스티커 모으기

### 스티커란? 🎨

스티커는 할 일을 완료할 때마다 받는 특별한 보상이에요!
총 25개의 스티커가 있고, 모두 모으는 게 목표예요!

### 스티커 종류

**1. 동물 스티커** 🐰
- 토끼 🐰, 고양이 🐱, 강아지 🐶, 판다 🐼, 유니콘 🦄

**2. 음식 스티커** 🍬
- 사탕 🍬, 아이스크림 🍦, 케이크 🍰, 도넛 🍩, 초콜릿 🍫

**3. 자연 스티커** ⭐
- 별 ⭐, 달 🌙, 해 ☀️, 무지개 🌈, 꽃 🌸

**4. 트로피 스티커** 🏆
- 금메달 🥇, 은메달 🥈, 동메달 🥉, 왕관 👑, 트로피 🏆

**5. 이모지 스티커** 😊
- 웃음 😊, 하트 ❤️, 박수 👏, 최고 👍, 불꽃 🔥

### 스티커 등급

스티커마다 나올 확률이 달라요!

- **✨ 일반 (60%)**: 자주 받을 수 있어요
- **💎 레어 (25%)**: 가끔 받을 수 있어요
- **🌟 에픽 (12%)**: 운이 좋으면 받을 수 있어요
- **👑 전설 (3%)**: 아주아주 운이 좋아야 받을 수 있어요!

### 스티커 모음판 보기

**방법**:
1. 화면 아래의 **"🎨 스티커"** 탭을 눌러요
2. 지금까지 모은 스티커를 볼 수 있어요

**화면 구성**:
```

│  25개 중 12개 수집! (48%)               │
│  ▰▰▰▰▰▱▱▱▱▱                           │
├─────────────────────────────────────────┤
│  [🐰] [🐱] [?]   ← 동물                │
│  [?]  [?]  [?]                         │
│                                          │
│  [🍬] [?]  [?]   ← 음식                │
│  [?]  [?]                              │
│                                          │
│  [⭐] [?]  [?]   ← 자연                │
│  ...                                     │
```

**아이콘 설명**:
- **컬러 이모지** (🐰): 받은 스티커
- **물음표** (?): 아직 받지 못한 스티커

**💡 꿀팁**:
- 매일 할 일을 완료하면 빠르게 모을 수 있어요
- 전설 등급 스티커를 받으면 친구에게 자랑해보세요!
- 같은 스티커를 여러 번 받을 수도 있어요 (모음판에는 1개만 표시)

## 진행도 보기

### 진행도 바 📊

할 일을 완료할 때마다 진행도 바가 채워져요!

**표시 내용**:
- **숫자**: "3/5" → 5개 중 3개 완료
- **퍼센티지**: "60%" → 60% 완료
- **막대**: 파란색 막대가 점점 길어져요
- **축하 메시지**: 100% 완료 시 "모두 완료했어요! 최고예요!"

**예시**:
```
처음: 0/3 (0%)  ▱▱▱▱▱▱▱▱▱▱
1개: 1/3 (33%) ▰▰▰▱▱▱▱▱▱▱
2개: 2/3 (67%) ▰▰▰▰▰▰▰▱▱▱
완료: 3/3 (100%) ▰▰▰▰▰▰▰▰▰▰
            🎉 모두 완료했어요! 최고예요!
```

## 자주 묻는 질문

### Q1: 할 일을 완료했는데 스티커가 안 나와요!

**A**: 체크박스를 정확히 눌렀는지 확인해보세요.
- 동그라미가 파란색으로 바뀌었나요?
- 할 일에 줄이 그어졌나요?
- 브라우저를 새로고침해보세요 (F5 키)

### Q2: 실수로 할 일을 삭제했어요. 되돌릴 수 있나요?

**A**: 안타깝게도 삭제한 할 일은 되돌릴 수 없어요.
- 다시 입력해야 해요
- 중요한 할 일은 신중하게 삭제하세요

### Q3: 스티커를 언제 받을 수 있나요?

**A**: 할 일을 완료할 때마다 자동으로 받아요!
- 체크박스를 누르면 바로 팝업이 나타나요
- 스티커는 랜덤으로 받아요 (어떤 스티커를 받을지 모르는 재미!)

### Q4: 같은 스티커를 여러 번 받을 수 있나요?

**A**: 네, 받을 수 있어요!
- 하지만 모음판에는 1개만 표시돼요
- 레어한 스티커는 여러 번 받아도 기뻐요!

### Q5: 어제의 할 일을 오늘 완료해도 스티커를 받나요?

**A**: 네, 받아요!
- 언제 완료하든 스티커를 받을 수 있어요
- 하지만 오늘의 진행도에는 포함되지 않아요

### Q6: 할 일을 완료했다가 다시 체크를 풀면 어떻게 되나요?

**A**: 다시 미완료 상태로 돌아가요.
- 하지만 받은 스티커는 사라지지 않아요
- 이미 받은 스티커는 계속 가질 수 있어요

### Q7: 컴퓨터를 껐다 켜도 할 일이 저장되나요?

**A**: 네, 자동으로 저장돼요!
- 찍찍이는 브라우저에 자동 저장해요
- 컴퓨터를 껐다 켜도, 브라우저를 닫았다 열어도 그대로 있어요
- ⚠️ 하지만 브라우저 데이터를 지우면 사라져요

### Q8: 친구와 스티커를 공유할 수 있나요?

**A**: 아직은 안 돼요!
- 지금은 혼자 사용하는 앱이에요
- 나중에 친구 기능이 추가될 수도 있어요

### Q9: 한 번에 몇 개까지 할 일을 추가할 수 있나요?

**A**: 제한이 없어요!
- 원하는 만큼 추가할 수 있어요
- 하지만 너무 많으면 힘들 수 있어니 적당히!

### Q10: 스티커를 모두 모으면 어떻게 되나요?

**A**: 25개를 모두 모으면 100% 달성이에요!
- 진행도가 "25개 중 25개 수집! (100%)"로 표시돼요
- 친구들에게 자랑해보세요! 🎉

## 도움말

### 단축키

- **Enter**: 할 일 추가 / 수정 저장
- **Esc**: 수정 취소
- **Tab**: 다음 요소로 이동

### 문제가 생겼을 때

1. **브라우저 새로고침** (F5 키)
2. **캐시 삭제**:
   - Chrome: Ctrl+Shift+Delete → "캐시된 이미지 및 파일" 체크 → 삭제
3. **다른 브라우저 사용** (Chrome, Safari, Firefox)

### 연락처

문제가 계속 발생하면:
- 부모님께 말씀드리세요
- 선생님께 도움을 요청하세요
- GitHub Issues에 문의하세요
