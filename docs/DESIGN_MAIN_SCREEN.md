# 메인 화면 (할 일 목록) 디자인 명세서

## 개요

찍찍이 앱의 메인 화면은 오늘의 할 일 목록을 표시하고 관리하는 핵심 화면입니다.
초등학생이 쉽게 사용할 수 있도록 직관적이고 명확한 UI로 디자인되었습니다.

---

## 레이아웃 구조

```
┌─────────────────────────────────────┐
│          헤더 (Header)              │
│   찍찍이 (Tick-Tick-E) + 응원 메시지 │
├─────────────────────────────────────┤
│                                     │
│  ┌─────────────────────────────┐   │
│  │   진행도 바 (ProgressBar)    │   │
│  │   오늘의 할 일: 2/5          │   │
│  │   [========>    ] 40%       │   │
│  └─────────────────────────────┘   │
│                                     │
│  ┌─────────────────────────────┐   │
│  │  ○ 수학 숙제하기            │   │
│  └─────────────────────────────┘   │
│                                     │
│  ┌─────────────────────────────┐   │
│  │  ○ 방 청소하기              │   │
│  └─────────────────────────────┘   │
│                                     │
│  ┌─────────────────────────────┐   │
│  │  ✓ 강아지 밥 주기     ✨    │   │
│  └─────────────────────────────┘   │
│                                     │
├─────────────────────────────────────┤
│          푸터 (Footer)              │
│   ✨ 스티커 안내 메시지              │
└─────────────────────────────────────┘
```

## 1. 할 일 목록 레이아웃

### 컨테이너
- **배경**: 흰색 카드 (`bg-white rounded-3xl shadow-lg`)
- **패딩**: 24px (p-6)
- **최대 너비**: 672px (max-w-2xl)
- **중앙 정렬**: mx-auto

### 할 일 항목 간격
- **항목 간 여백**: 12px (space-y-3)
- **항목 내부 패딩**: 16px (p-4)

---

## 2. 완료/미완료 항목 시각적 구분

### 미완료 항목 (기본 상태)

**배경 및 테두리**:
- 배경색: 흰색 (`bg-white`)
- 테두리: 2px 회색 (`border-2 border-gray-200`)
- 호버 시: 파란색 테두리 (`hover:border-primary/50`)

**체크박스**:
- 크기: 40x40px (`w-10 h-10`)
- 모양: 원형 (`rounded-full`)
- 테두리: 4px 회색 (`border-4 border-gray-300`)
- 배경: 흰색 (`bg-white`)
- 호버 시: 파란색 테두리 (`hover:border-primary`)

**텍스트**:
- 색상: 진한 회색 (`text-gray-800`)
- 크기: 18px (`text-kid-base`)
- 굵기: 중간 (`font-medium`)

### 완료 항목 (체크된 상태)

**배경 및 테두리**:
- 배경색: 연한 초록색 (`bg-accent-green/20`)
- 테두리: 2px 초록색 (`border-2 border-accent-green`)

**체크박스**:
- 배경: 파란색 (`bg-primary`)
- 테두리: 4px 파란색 (`border-4 border-primary`)
- 크기 확대: 110% (`scale-110`)
- 체크 아이콘: 흰색 SVG (✓)

**텍스트**:
- 색상: 회색 (`text-gray-500`)
- 취소선: 적용 (`line-through`)
- 크기: 18px (`text-kid-base`)

**완료 이모지**:
- 아이콘: ✨
- 크기: 24px (`text-2xl`)
- 애니메이션: pop 효과 (`animate-pop`)

### 시각적 비교

| 요소 | 미완료 | 완료 |
|------|--------|------|
| 배경 | 흰색 | 연한 초록색 |
| 테두리 | 회색 | 초록색 |
| 체크박스 배경 | 흰색 | 파란색 |
| 텍스트 | 검은색 | 회색 + 취소선 |
| 특수 표시 | 없음 | ✨ 이모지 |

## 3. 완료율 표시 영역 (ProgressBar)

### 레이아웃

**상단 정보 바**:
- 왼쪽: "오늘의 할 일" (굵은 회색 텍스트)
- 오른쪽: "2/5" (굵은 파란색 텍스트)
- 간격: space-between

**진행 바**:
- 높이: 32px (`h-8`)
- 배경: 회색 (`bg-gray-200`)
- 모서리: 완전히 둥글게 (`rounded-full`)
- 진행 부분: 파란색→핑크색 그라데이션 (`from-primary to-secondary`)
- 애니메이션: 부드러운 너비 전환 (`transition-all duration-500`)

**퍼센트 표시**:
- 위치: 진행 바 내부 중앙
- 색상: 흰색 (`text-white`)
- 굵기: 굵게 (`font-bold`)
- 크기: 16px (`text-kid-sm`)

### 100% 완료 시 축하 메시지

```
🎉 모두 완료했어요! 최고예요!
```

- 위치: 진행 바 아래 중앙
- 색상: 핑크색 (`text-secondary`)
- 이모지 크기: 20px (`text-kid-lg`)
- 여백: 상단 12px (`mt-3`)

### 상태별 시각화

| 완료 상태 | 진행 바 너비 | 퍼센트 | 특수 표시 |
|-----------|--------------|--------|-----------|
| 0/5 | 0% | - | 없음 |
| 2/5 | 40% | 40% | 없음 |
| 3/5 | 60% | 60% | 없음 |
| 5/5 | 100% | 100% | 🎉 축하 메시지 |

## 4. 빈 상태 화면 (EmptyState)

할 일이 하나도 없을 때 표시되는 안내 화면입니다.

### 레이아웃

**중앙 정렬 컨테이너**:
- 패딩: 상하 48px (`py-12`)
- 정렬: 중앙 (`text-center`)

**이모지 아이콘**:
- 아이콘: 📝
- 크기: 128px (`text-8xl`)
- 애니메이션: 위아래 튀기기 (`animate-bounce`)

**제목**:
- 텍스트: "할 일이 없어요!"
- 색상: 진한 회색 (`text-gray-700`)
- 크기: 24px (`text-kid-xl`)
- 굵기: 굵게 (`font-bold`)
- 여백: 하단 8px (`mb-2`)

**설명 텍스트**:
- 텍스트: "오늘 할 일을 추가해보세요"
- 색상: 회색 (`text-gray-500`)
- 크기: 18px (`text-kid-base`)
- 여백: 하단 24px (`mb-6`)

**추가 버튼**:
- 스타일: 기본 버튼 (`btn-primary`)
- 텍스트: "할 일 추가하기"

## 인터랙션 및 애니메이션

### 1. 체크박스 클릭
- **트리거**: 사용자가 체크박스 클릭
- **효과**:
  - 체크박스 배경색 변경 (흰색 → 파란색)
  - 체크 아이콘 표시
  - 크기 확대 애니메이션 (scale-110)
  - 텍스트 취소선 적용
  - ✨ 이모지 표시 (pop 애니메이션)
- **지속 시간**: 300ms (`transition-all duration-300`)

### 2. 진행 바 업데이트
- **트리거**: 할 일 완료/미완료 상태 변경
- **효과**: 진행 바 너비 부드럽게 변경
- **지속 시간**: 500ms (`transition-all duration-500`)

### 3. 100% 완료 시
- **효과**: 축하 메시지 표시 (🎉 모두 완료했어요!)
- **조건**: `completedCount === totalCount && totalCount > 0`

### 4. 호버 효과
- **미완료 항목**: 테두리 색상 변경 (회색 → 파란색 50% 투명도)
- **체크박스**: 테두리 색상 강조 (회색 → 파란색)
- **삭제 버튼**: 배경 변경 (회색 → 빨간색), 아이콘 색상 변경

### 키보드 내비게이션
- 체크박스: Tab 키로 포커스 이동

### 시각적 피드백
- 최소 터치 영역: 44x44px (Apple/Google 권장 기준)

### 스크린 리더
- 체크박스: `aria-label` 제공
- 삭제 버튼: `aria-label="삭제"` 제공

## 정렬 및 필터링

### 할 일 정렬 순서
1. **미완료 항목** (위)
2. **완료 항목** (아래)

**코드**:
```typescript
const sortedTasks = [...tasks].sort((a, b) => {
  if (a.isCompleted === b.isCompleted) return 0;
  return a.isCompleted ? 1 : -1;
});
```

### 날짜 필터링
- 오늘 날짜의 할 일만 표시
- `getTodayTasks()` 함수 사용

## 사용자 흐름 (User Flow)

```
1. 페이지 로드
   ↓
2. 로컬 스토리지에서 오늘의 할 일 로드
   ↓
3a. 할 일 있음          3b. 할 일 없음
   ↓                      ↓
4a. 진행도 바 표시      4b. 빈 상태 화면 표시
   ↓                      ↓
5a. 할 일 목록 표시     5b. "할 일 추가하기" 버튼
   ↓
6. 사용자가 체크박스 클릭
   ↓
7. 완료 상태 토글
   ↓
8. 애니메이션 효과
   ↓
9. 로컬 스토리지 업데이트
   ↓
10. 진행도 바 업데이트
   ↓
11. (완료 시) 스티커 보상 로직 트리거
```
