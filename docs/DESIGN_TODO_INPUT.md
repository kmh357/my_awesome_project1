# 할 일 추가 입력 화면 디자인 명세서

## 개요

할 일을 추가하는 입력 영역은 사용자가 새로운 할 일을 등록하는 핵심 인터페이스입니다.
초등학생이 쉽게 이해하고 사용할 수 있도록 명확한 안내와 즉각적인 피드백을 제공합니다.

---

## 레이아웃 구조

```
┌──────────────────────────────────────────┐
│  ┌────────────────────┐  ┌─────────┐    │
│  │ 예: 수학 숙제하기... │  │  추가   │    │
│  └────────────────────┘  └─────────┘    │
│              5/50                        │
├──────────────────────────────────────────┤
│  ⚠️ 할 일을 입력해주세요!                 │  (에러 시에만 표시)
├──────────────────────────────────────────┤
│  💡 팁: 구체적으로 적을수록 좋아요!       │
└──────────────────────────────────────────┘
```

## 1. 입력 필드 디자인

### 기본 스타일

**크기 및 패딩**:
- 패딩: 12px 좌우, 12px 상하 (`px-4 py-3`)
- 높이: 자동 (패딩 포함 약 48px)
- 최소 터치 영역: 44x44px (모바일 접근성)

**테두리 및 배경**:
- 배경색: 흰색 (`bg-white`)
- 테두리: 2px 회색 (`border-2 border-gray-300`)
- 모서리: 둥근 모서리 12px (`rounded-xl`)

**폰트**:
- 크기: 18px (`text-kid-base`)
- 색상: 검은색 (기본 텍스트 색상)
- 폰트 패밀리: Noto Sans KR

### Placeholder

**텍스트**: "예: 수학 숙제하기, 강아지 밥 주기"

**스타일**:
- 색상: 연한 회색 (브라우저 기본값)
- 이탤릭: 없음
- 투명도: 약 60%

**목적**: 사용자에게 구체적인 입력 예시를 제공하여 이해를 돕습니다.

### 포커스 상태

**테두리**:
- 색상: 파란색 (`focus:border-primary`)
- 두께: 2px (유지)

**링(Ring)**:
- 색상: 파란색 20% 투명도 (`focus:ring-primary/20`)
- 두께: 2px (`focus:ring-2`)
- 외곽선: 없음 (`focus:outline-none`)

**전환 효과**:
- 지속 시간: 200ms (`transition-all duration-200`)
- Easing: 기본 (ease)

### 에러 상태

**테두리**:
- 색상: 빨간색 (`border-red-400`)
- 포커스 시: 진한 빨간색 (`focus:border-red-500`)

**링(Ring)**:
- 색상: 빨간색 10% 투명도 (`focus:ring-red-100`)

### 상태별 비교

| 상태 | 테두리 색상 | 링 색상 | 배경색 |
|------|-------------|---------|--------|
| 기본 | 회색 (#D1D5DB) | - | 흰색 |
| 포커스 | 파란색 (#6B9BD1) | 파란색 20% | 흰색 |
| 에러 | 빨간색 (#F87171) | 빨간색 10% | 흰색 |

## 2. 추가 버튼 디자인

### 기본 스타일

**크기**:
- 최소 너비: 44px (접근성)
- 최소 높이: 44px (접근성)
- 실제 너비: 자동 (패딩 + 텍스트)
- 패딩: 12px 상하, 32px 좌우 (`py-3 px-8`)

**배경 및 테두리**:
- 배경색: 파란색 (`bg-primary #6B9BD1`)
- 테두리: 없음
- 모서리: 둥근 모서리 16px (`rounded-2xl`)

**텍스트**:
- 내용: "추가"
- 색상: 흰색 (`text-white`)
- 크기: 18px (`text-kid-base`)
- 굵기: 굵게 (`font-bold`)

**그림자**:
- 기본: 큰 그림자 (`shadow-lg`)
- 호버 시: 더 큰 그림자 (`hover:shadow-xl`)

### 호버 상태

**배경색**: 진한 파란색 (`hover:bg-primary-dark #4A7BA7`)

**크기 변화**: 105% 확대 (`transform hover:scale-105`)

**전환 효과**: 300ms 부드러운 전환 (`transition-all duration-300`)

### 비활성 상태

**조건**: 입력 필드가 비어있거나 공백만 있을 때

**스타일**:
- 배경색: 회색 (브라우저 기본 disabled 스타일)
- 투명도: 50% 정도
- 커서: 비활성 (`cursor-not-allowed`)
- 호버 효과: 없음

**구현**:
```typescript
disabled={!inputValue.trim()}
```

### 버튼 상태별 비교

| 상태 | 배경색 | 그림자 | 크기 | 커서 |
|------|--------|--------|------|------|
| 기본 | 파란색 | 큰 | 100% | pointer |
| 호버 | 진한 파란색 | 더 큰 | 105% | pointer |
| 비활성 | 회색 | 없음 | 100% | not-allowed |

## 3. 에러 메시지 표시 영역

### 레이아웃

**위치**: 입력 필드와 버튼 아래

**여백**: 상단 12px (`mt-3`)

**패딩**: 12px 전체 (`p-3`)

### 스타일

**배경 및 테두리**:
- 배경색: 연한 빨간색 (`bg-red-50`)
- 테두리: 2px 빨간색 (`border-2 border-red-200`)
- 모서리: 둥근 모서리 12px (`rounded-xl`)

**레이아웃**:
- 방향: 가로 (`flex`)
- 정렬: 중앙 (`items-center`)
- 간격: 8px (`gap-2`)

**아이콘**:
- 이모지: ⚠️
- 크기: 24px (`text-2xl`)

**텍스트**:
- 색상: 빨간색 (`text-red-600`)
- 크기: 18px (`text-kid-base`)
- 굵기: 중간 (`font-medium`)

### 에러 메시지 종류

| 조건 | 메시지 |
|------|--------|
| 빈 입력 | "할 일을 입력해주세요!" |
| 글자 수 초과 | "할 일은 최대 50자까지 입력할 수 있어요!" |

### 표시 조건

- 에러가 있을 때만 표시 (`{error && ...}`)
- 입력 값이 변경되면 에러 자동 초기화
- 폼 제출 실패 시에만 에러 표시

## 4. 글자 수 카운터 디자인

### 위치 및 정렬

**위치**: 입력 필드 아래 오른쪽

**여백**: 상단 8px (`mt-2`)

**정렬**: 오른쪽 정렬 (`text-right`)

### 스타일

**기본 상태** (제한 이내):
- 색상: 연한 회색 (`text-gray-400`)
- 크기: 16px (`text-kid-sm`)
- 굵기: 보통

**초과 상태** (제한 초과):
- 색상: 빨간색 (`text-red-500`)
- 크기: 16px (`text-kid-sm`)
- 굵기: 굵게 (`font-bold`)

**전환 효과**: 부드러운 색상 전환 (`transition-colors`)

### 표시 형식

**형식**: `현재글자수/최대글자수`

**예시**:
- `0/50` (비어있음)
- `15/50` (정상)
- `50/50` (최대)
- `55/50` (초과, 빨간색 + 굵게)

### 로직

```typescript
const currentLength = inputValue.length;
const isOverLimit = currentLength > maxLength;
```

### 상태별 비교

| 글자 수 | 색상 | 굵기 | 예시 |
|---------|------|------|------|
| 0-50 | 회색 | 보통 | 25/50 |
| 51+ | 빨간색 | 굵게 | **52/50** |

## 인터랙션 및 애니메이션

### 1. 입력 필드 포커스
- **트리거**: 사용자가 입력 필드 클릭
- **효과**: 테두리 색상 변경 (회색 → 파란색), 링 표시
- **지속 시간**: 200ms

### 2. 버튼 호버
- **트리거**: 마우스 오버
- **효과**: 배경색 변경, 그림자 확대, 크기 105% 확대
- **지속 시간**: 300ms

### 3. 버튼 클릭 (폼 제출)
- **트리거**: 사용자가 "추가" 버튼 클릭 또는 Enter 키 입력
- **동작**:
  1. 유효성 검증 실행
  2. 성공 시: 할 일 추가, 입력 필드 초기화
  3. 실패 시: 에러 메시지 표시

### 4. Enter 키 입력
- **트리거**: 입력 필드에서 Enter 키 입력
- **동작**: 폼 제출 (버튼 클릭과 동일)

### 5. 글자 수 초과
- **트리거**: 글자 수가 50자 초과
- **효과**: 카운터 색상 변경 (회색 → 빨간색 + 굵게)
- **전환**: 부드러운 색상 전환

### 6. 에러 자동 초기화
- **트리거**: 사용자가 입력 값 변경
- **효과**: 에러 메시지 사라짐

## 유효성 검증 로직

### 1. 빈 값 검증

```typescript
const trimmedValue = inputValue.trim();
if (!trimmedValue) {
  setError('할 일을 입력해주세요!');
  return;
}
```

**조건**: 입력 값이 공백만 있거나 비어있음

**에러**: "할 일을 입력해주세요!"

### 2. 글자 수 제한 검증

```typescript
if (trimmedValue.length > maxLength) {
  setError(`할 일은 최대 ${maxLength}자까지 입력할 수 있어요!`);
  return;
}
```

**조건**: 입력 값이 50자 초과

**에러**: "할 일은 최대 50자까지 입력할 수 있어요!"

### 3. 성공 시 처리

```typescript
onAdd(trimmedValue);
setInputValue('');
setError('');
```

**동작**:
1. `onAdd` 콜백 호출 (부모 컴포넌트에 전달)
2. 입력 필드 초기화
3. 에러 메시지 초기화

## 접근성 (Accessibility)

### 키보드 내비게이션

**Tab 키**:
- 입력 필드 → 추가 버튼 순서로 포커스 이동

**Enter 키**:
- 입력 필드에서 Enter 키로 폼 제출 가능

### 시각적 피드백

**포커스 표시**:
- 명확한 테두리 색상 변경
- 링 효과로 포커스 강조

**에러 표시**:
- 빨간색 테두리 + 에러 메시지
- 아이콘(⚠️)으로 시각적 경고

### 터치 영역

**최소 크기**: 44x44px (Apple/Google 권장 기준)

**버튼**: 48px 이상 (패딩 포함)
